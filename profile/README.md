# Managoat libraries

Small, focused Elixir libraries extracted from [Fountain](https://github.com/BinaryBourbon/fountain) and published under Apache-2.0.

- [`managoat_substitution`](https://hexdocs.pm/managoat_substitution/) — `${VAR}` substitution over nested configuration, with escaping and every missing key reported at once.
- [`managoat_mcp_auth`](https://hexdocs.pm/managoat_mcp_auth/) — MCP authorization discovery with a server-side URL guard.
- [`managoat_oauth`](https://hexdocs.pm/managoat_oauth/) — OAuth 2.0 authorization code with PKCE and device grant state machines behind a host behaviour.
- [`managoat_acp`](https://hexdocs.pm/managoat_acp/) — A client-side Agent Client Protocol session with permissions, normalised blocks, usage accounting, and tracing.
- [`managoat_sandbox`](https://hexdocs.pm/managoat_sandbox/) — One sandbox behaviour over Sprites, E2B, and Daytona, with an executable conformance suite.
- [`managoat_docs`](https://hexdocs.pm/managoat_docs/) — A compile-time embedded Phoenix manual with Markdown rendering and documentation guardrails.
- [`managoat_broker`](https://hexdocs.pm/managoat_broker/) — An egress proxy that replaces credential placeholders at the network boundary.
- [`managoat_runner`](https://hexdocs.pm/managoat_runner/) — A self-hosted runner wire protocol and sandbox adapter behind a host behaviour.
